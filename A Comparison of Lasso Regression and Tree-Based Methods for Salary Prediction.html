1. Introduction

Understanding the factors that influence salary is important for both individuals and organizations. Salaries vary widely depending on experience, education, job role and location, but the extent to which each factor contributes is not always clear. This project aims to model salary as a function of these characteristics and evaluate how well different predictive methods perform. The analysis uses the Job Salary Prediction Dataset obtained from Kaggle, which contains information on job roles, years of experience, education level, skills count, industry, company size, location, remote work status, certifications and salary outcomes (Kaggle, n.d.). The dataset includes a large number of observations and a mix of numerical and categorical variables, making it well-suited for comparing both linear and tree-based models. To address this problem, several models were applied, including Lasso regression as a baseline and three tree-based methods: Bagging, Random Forest, and Boosting. These approaches differ in how they capture relationships in the data, particularly in their ability to model nonlinear effects and interactions (Hastie, Tibshirani, & Friedman, 2009). The results show that Boosting provides the best predictive performance, while Lasso remains competitive due to strong linear relationships in the data. The analysis highlights both the strengths and limitations of each method and provides insight into the key drivers of salary.

2. Problem Definition and Model

2.1 Task Definition

The goal of this analysis is to predict salary based on a set of predictor variables including job title, years of experience, education level, skills count, industry, company size, location, remote work status and certifications. The problem is non-trivial because many predictors are categorical with multiple levels. The relationships may be both linear and nonlinear. Interactions between variables (e.g., experience and job role) may affect salary. This is a regression problem where:

  • Input (X): Job and individual characteristics
  • Output (Y): Salary

2.2 Model Definition

Four modeling approaches were used-

Lasso Regression:

A linear model with regularization that shrinks coefficients and performs variable selection (Tibshirani, 1996).

Bagging:

An ensemble method that builds multiple decision trees using bootstrap samples and averages their predictions (Breiman, 1996).

Random Forest:

A variation of bagging that introduces randomness by selecting a subset of predictors at each split (Breiman, 2001).

Boosting:

A sequential method where each tree corrects the errors of the previous one, allowing the model to capture complex patterns (Friedman, 2001).

Each model was trained and evaluated using a consistent train-test split to ensure fair comparison.

3. Methodology (Model Selection)

3.1 Experimental Setup

The dataset was split into training (70%) and test (30%) sets. Model performance was evaluated using Mean Squared Error (MSE), which measures the average squared difference between predicted and actual salary values (Hastie et al., 2009). Lasso regression was used as the baseline model. Tree-based methods were then applied and compared against this baseline. Due to the large size of the dataset and to ensure computational feasibility, reduced training samples and fewer trees were used for tree-based models. These adjustments allowed meaningful comparisons without excessive runtime.

LLM assistance was used to help troubleshoot R code, generate initial model implementation ideas, and clarify interpretations of model results. All code, analysis decisions and written interpretations were reviewed and modified manually.

Overall, the goal of this comparison is not only to identify the best-performing model, but also to understand how different modeling approaches behave under the same data conditions.

3.2 Results

Lasso Regression

Lasso regression achieved a test MSE of 51,084,437. It performed well despite its simplicity, indicating that many relationships between predictors and salary are approximately linear. Additionally, Lasso retained key variables such as experience, skills count, education level and location, while shrinking less informative variables to zero (Tibshirani, 1996).

cv_lasso <- cv.glmnet(x_train, y_train, alpha = 1)
best_lambda <- cv_lasso$lambda.min

lasso_model <- glmnet(x_train, y_train, alpha = 1, lambda = best_lambda)

pred_lasso <- predict(lasso_model, s = best_lambda, newx = x_test)

mse_lasso <- mean((y_test - pred_lasso)^2)

Bagging

The bagging model produced a significantly higher MSE of 125,322,635, indicating poor predictive performance. This result is likely driven by the high dimensionality of the data set and the use of all predictors at each split, which can lead to unstable and overly complex trees (Breiman, 1996). The reduced sample size and number of trees, necessary for computational reasons, may have further limited performance.

Random Forest

Random Forest models were evaluated using different values of mtry, which controls how many predictors are considered at each split. Lower values of mtry introduce more randomness and reduce variance, while higher values increase model complexity (Breiman, 2001). Despite tuning, the best Random Forest model achieved an MSE of 184,889,132, which was worse than Lasso. This suggests that increasing model complexity did not improve predictive performance for this dataset.

As shown in Figure 1, Random Forest identified experience, location and education as important predictors.

Boosting

Boosting achieved the lowest test MSE of 46,731,953, making it the best-performing model. Different combinations of the number of trees, shrinkage rate and tree depth were tested. Lower shrinkage values and shallow trees improved performance by allowing the model to learn gradually and avoid overfitting. The sequential nature of boosting enables it to capture patterns that other models miss (Friedman, 2001).

Figure 2 demonstrates that Boosting assigned particularly high importance to location and experience.

3.3 Discussion

The results show that Boosting outperformed all other models, while Lasso remained competitive. This suggests that the data contains both linear and nonlinear relationships. The poor performance of Bagging and Random Forest was somewhat unexpected, as these methods are often strong performers. However, in this case, their reliance on many predictors and complex trees may have led to overfitting or instability, particularly given the computational constraints. Lasso performed well because key predictors such as experience and education have relatively direct, linear relationships with salary. Boosting improved upon this by capturing additional structure in the data. The Boosting model identifies several important predictors of salary. Salary increases consistently with experience, reflecting career progression. Individuals with more skills tend to earn higher salaries. Advanced degrees (Master’s, PhD) are associated with higher earnings. Salaries vary significantly by region, with some countries offering higher compensation. These findings are consistent with expectations and were also supported by the Lasso model, which strengthens confidence in their importance. Overall, salary appears to be driven by a combination of human capital (skills, education), experience, and geographic factors.Although Boosting achieved the best predictive performance, Lasso regression remained more interpretable because the model coefficients directly show the relationship between predictors and salary.

4. Limitations and Future Work

This analysis has several limitations. First, computational constraints required reducing sample sizes and limiting the number of trees, which may have affected model performance. Second, the dataset may not capture all relevant factors influencing salary, such as company performance or negotiation effects. Future work could include using the full dataset with more computational resources, testing additional models such as gradient boosting variants, incorporating interaction terms or feature engineering.

5. Conclusion

This project compared Lasso regression and tree-based methods for predicting salary. Boosting achieved the best performance, followed closely by Lasso, while Bagging and Random Forest performed worse. The results demonstrate that while complex models can improve predictive accuracy, simpler models can still perform well when relationships are largely linear. The findings also highlight the importance of experience, skills, education and location as key drivers of salary.
